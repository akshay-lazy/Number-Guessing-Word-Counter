# Number Guessing Game & Word Counter

A beginner-friendly Python CLI project that combines an interactive Number Guessing Game with a file-based Word Counter.

## Features

### 1. Number Guessing Game
- Generates random numbers using Python's `random` module.
- Allows users to guess a number between 1 and 100.
- Provides hints such as "Too High" and "Too Low".
- Tracks the number of attempts.
- Includes a scoring system based on attempts.

### 2. Word Counter
- Reads text from a `.txt` file.
- Counts the total number of words.
- Counts the total number of characters.
- Analyses the frequency of individual words.
- Identifies frequently used words.

## Technologies Used
